# SECOND LIFE — GitHub Pages 버전

은퇴 후의 삶을 체험하는 한국어 웹게임 MVP입니다.

## 파일
- `index.html` : 게임 화면과 기본 구조
- `style.css` : 반응형 디자인
- `game.js` : 게임 규칙, 주민 대화, 저장 기능

## 실행
1. 세 파일을 같은 폴더에 둡니다.
2. `index.html`을 브라우저에서 열면 실행됩니다.
3. 진행 상황은 브라우저의 `localStorage`에 자동 저장됩니다.

## GitHub Pages 배포
1. GitHub에서 새 Public 저장소를 만듭니다. 예: `second-life`
2. 이 폴더 안의 세 파일을 저장소 최상위(root)에 업로드합니다.
3. 저장소의 Settings → Pages로 이동합니다.
4. Build and deployment에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/ (root)`로 선택하고 Save를 누릅니다.
6. 잠시 후 표시되는 Pages 주소로 접속합니다.

## 현재 구현된 기능
- 첫 시작 설정: 이름, 나이, 전직, 가치관, 관심사, 자녀 여부
- 동네 화면과 건물 상호작용
- 주민 3명, 주민별 친밀도 및 대화 이력
- 키워드 기반 기본 대화 엔진과 간단한 기억
- 하루 진행, 연금 수입과 생활비 반영, 나이 증가
- 활동: 산책, 카페, 배움, 봉사, 운동, 정원, 악기, 파트타임, 여행
- 다섯 영역 점수 및 생활 만족도
- 부동산: 추가 주택 구매, 주택 판매 예약, 집 꾸미기
- 인생 기록, 은퇴 유형, What-if 장면, TXT 내보내기
- 자동 저장 및 불러오기

## 현재 버전의 한계
- 주민 대화는 생성형 AI가 아니라 키워드 기반 로컬 대화 엔진입니다.
- 저장 데이터는 현재 브라우저에만 보관됩니다. 다른 기기와 동기화되지 않습니다.
- 서버 계정, 실제 AI API, PDF 리포트, 기관용 대시보드는 아직 연결되지 않았습니다.
- 마을은 CSS 기반 일러스트형 화면이며, 자유 이동형 맵은 아닙니다.
- 게임 내 돈과 점수는 가상 수치이며 현실의 금융 조언이 아닙니다.

## 데이터 초기화
오른쪽 프로필 카드의 ↻ 버튼을 누르고 초기화를 확인하면 현재 브라우저의 게임 저장 데이터가 삭제됩니다.
